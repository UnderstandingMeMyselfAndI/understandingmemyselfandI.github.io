# Project Best Practices

- Always use external .scss files for css
- .scss files should be created next to the component files
- Always use css selectors in component structure
- Create css properties for the selectors that allow display and functionality to be assessed
- Always confirm the removal of exisiting css selectors
- Always confirm the removal of component features
- Do not claim the solution is perfect
- When making fundamental changes highlight any features removed or prevented from working
